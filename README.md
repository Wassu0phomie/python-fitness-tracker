**FITAPP** — это веб-приложение для управления тренировочным процессом, вдохновленное современными фитнес-платформами. Проект сочетает в себе мощный бэкенд на Django и динамичный интерфейс с неоновым дизайном.

---

## ✨ Основные функции

* **📊 Dashboard Пользователя:** Персонализированный профиль с графиками активности.
* **🏋️ Библиотека упражнений:** База упражнений с фильтрацией по группам мышц, оборудованию и сложности.
* **📅 Планировщик тренировок:** Создание кастомных планов и отслеживание выполнения.
* **📸 Прогресс в фото:** Галерея для визуального мониторинга изменений тела.
* **⚡ Динамический интерфейс:** Использование HTMX для обновления данных без перезагрузки страниц.

---

## 🎨 Дизайн и UI

Интерфейс выполнен в стиле **High-Contrast Neon**:
- **Цветовая палитра:** Глубокий черный, чистый белый и акцентный неоновый лайм (`#D7FD51`).
- **Шрифты:** Modern Sans-serif (Inter).
- **Адаптивность:** Полная поддержка мобильных устройств благодаря Bootstrap 5.

---

## 🚀 Технологический стек

- **Backend:** Python 3.12, Django 4.2+
- **Database:** PostgreSQL (production), SQLite (development)
- **Frontend:** HTML5, CSS3, JavaScript, HTMX
- **Media Handling:** Поддержка современных форматов (WebP) для быстрой загрузки фото упражнений.
- **Инструменты:** Django Bootstrap 5, UI Avatars API.
